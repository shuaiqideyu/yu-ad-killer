# 雨の广告杀手

Telegram 群广告治理机器人。协议号会换邀请链接，哈希变了，群还是那一个。普通关键词对不上这种广告。这个机器人把链接打开，只拿群名来比。

存储是 SQLite。缓存只在进程内存里。主机器人和每个克隆机器人各用各的库，关键词、白名单和管理员不串。

## 运行

需要 Go 1.25.7。

```bash
cp .env.example .env
# 填写 BOT_TOKEN、BOT_ADMIN_ID
go build -o chavipbot ./cmd/bot
./chavipbot
```

把机器人拉进群，并给它封禁成员和删除消息的权限。作者私聊发送 `/admin`，把工作群和播报频道绑好。关键词命令在工作群里用。

| 变量 | 作用 |
| --- | --- |
| `BOT_TOKEN` | 主机器人令牌 |
| `BOT_ADMIN_ID` | 作者的 Telegram 用户 ID，全局超管 |
| `BOT_WORK_GROUP_ID` | 可选。不填就在面板里绑定工作群 |
| `SQLITE_PATH` | 主库，默认 `data/chavipbot.db` |
| `CLONE_DB_DIR` | 克隆库目录，默认 `data/clones` |

## 命令

管理命令只认这个机器人自己的管理员。普通成员发命令没有回复。

| 命令 | 作用 |
| --- | --- |
| `/name` `/bio` `/msg` | 拉黑昵称、简介、消息里的关键词 |
| `/q` | 拉黑邀请链接背后的群名。`/q list` 查看 |
| `/z` | 转发来源的名称或用户名命中即拉黑转发者 |
| `/no` | 水群、刷屏白名单。只跳过这两项，不跳过广告检测 |
| `/lh` `/unlh` | 拉黑、解除拉黑。解除会同步到这个机器人登记过的管理群 |
| `/f` | 封禁。回复一条带文字的消息时，原文会收成消息关键词 |
| `/jy` `/unjy` `/un` | 禁言、解除。管理员回复机器人的提醒再发 `/un`，直接解开那个人 |
| `/t` | 踢出 |
| `加白` `移白` `白名单` | 用户白名单。白名单跳过自动处罚 |
| `/admin` | 管理面板：管理员、关键词、检测开关、绑定工作群 |
| `/add` | 仅主机器人作者，在私聊里添加克隆机器人 |
| `/reload` | 把关键词从数据库重新载入内存 |

## 检测思路

### 链接会变，群名不变

广告号在消息里挂 `t.me/+……` 或 `t.me/joinchat/……`。同一批群每天换链接，正文关键词对哈希无效。

`/q 小额洗资` 之后，消息正文、说明、隐藏链接和按钮里的 Telegram 链接会被打开。只拿群名或频道名做包含匹配。群简介不参与，简介很长，短词容易误伤。个人主页也不按这条处理。没有群名关键词时，不去访问任何链接。

同一个链接的群名会在进程里记住。同时只放少量预览请求，忙的时候这一次先跳过，不把后面的消息堵住。

### 进群就查，不等他说话

换号进群的广告号，昵称或简介里已经有关键词。如果等到第一条消息才查，广告会先在群里停一会儿。

两条进群入口一起用：

- 加入群组的系统消息。
- `chat_member`。邀请链接、审批、加入请求通过时，往往没有系统消息。

同一个人同一次进群可能打出两条更新，30 秒内只处理一次。已经封禁的号再进来，直接补踢。

### 先认出管理员，再谈删除

自动检测和命令清理不删群主、真人管理员、管理员机器人、匿名管理员，也不删机器人自己配置的管理员和作者。

拉不到管理员列表时，这条消息不进入自动删除。身份不清楚就宁可放过，也不把管理员的话删掉。管理员机器人不在缓存里时，再单独查一次身份。有人被提升或撤掉管理员时，立刻丢掉这份缓存。

### 俄语资料直接拉黑，群聊正文不查

中文群里，显示名、用户名、简介里的西里尔字母或俄罗斯地名，客户端语言 `ru`，以及商家地址、商家介绍里的同类内容，直接拉黑。不依赖关键词表。

不扫群消息正文。别人在中文群里讨论这些词，不该被当成广告号。单纯的拉丁转写名字，例如 Ivan，也不命中。

### 关键词不怕换皮

英文不区分大小写和全角半角，`vip`、`VIP`、`ＶＩＰ` 是同一个词。中文不区分简繁。能按 Unicode 折回的兼容汉字会折，形近字不猜。

词在载入和修改时折好。每条消息不再把整张词表重折一遍。启动或 `/reload` 时，同一种写法只留最早的一条。

### 转发、刷屏、名片是另一类广告

- 转发来源的名字或用户名命中 `/z`，删消息并拉黑转发的人。他自己打出来的字不受这条影响。
- 5 秒内 5 条完全相同的文字算刷屏。连续 5 条完全相同的文字算水群。中间插一条不同的内容，水群计数重新开始。命中后永久禁言。
- 同一人在同一群，2 秒内转发满 4 条，永久禁言，并删掉这几条。相册里每一条单独计数。编辑旧转发、频道同步到讨论组的消息不计数。
- 名片一律拉黑：自己的、别人的、只有电话的、带 Telegram 账号的、vCard 文件。真人群聊很少用名片发广告，广告号常用它绕开文字关键词。
- 遮罩文字和遮罩媒体按诱导点击处理。

这几条都让管理员和用户白名单先走。水群白名单只对刷屏和水群生效，广告关键词仍然会拦。

### 封禁和删消息分成两层

先把封禁写进自己的库，再拉黑，再删触发的那条消息。

`banChatMember` 会要求清掉这个人在群里的消息，但机器人没有删除消息权限时，这一步会静默失败。所以封禁成功之外，还会再显式删一次触发消息。封禁成功不等于消息已经清掉。

## 克隆

主机器人作者在私聊用 `/add` 添加另一个机器人令牌。克隆启动后使用自己的数据库、自己的管理员、工作群、关键词和白名单。主库里只多一张克隆机器人管理表。

跨机器人的封禁同步，只更新对方自己的库，并由对方处理它自己登记的群。
